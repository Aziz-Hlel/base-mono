# Future Schools Excellence Summit

Premium multilingual conference website built with React + Vite + TypeScript + Tailwind CSS + Framer Motion.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- /
- /about
- /program
- /speakers
- /workshops
- /audience
- /partners
- /register
- /contact

## Languages

- English
- Français
- العربية (RTL)

## Visual identity

Navy `#071A2B`, Deep Blue `#0B3155`, Royal Blue `#0B5CAD`, Sky `#4DA3D9`, Champagne `#C9A96E`, White / Mist.

The content is based on the supplied Future Schools Excellence Summit and AI for Schools 2027 documents. Replace placeholder contact details and speaker profiles before production.

## FES Summit 2027 – additional pages

This version adds dedicated Registration (`/register`), Sponsorship (`/sponsorship`) and Exhibition (`/exhibition`) pages in English, French and Arabic. The content follows the supplied FES 2027 publication copy. Public prices, sponsorship benefits and booth dimensions are proposed and must be approved before publication. The event month is shown as May 2027, in line with the supplied page copy.

The enquiry forms are front-end demonstrations only: connect them to a secure backend, CRM or email service before accepting live registrations or commercial enquiries. Payment checkout is not configured.

Run locally with `npm install` and `npm run dev`; create a production build with `npm run build`.
